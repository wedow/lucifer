# __buffer__ on C types that fill bf_getbuffer

numpy.ndarray and numpy.void have no __buffer__ attribute (two numpytest FAILs: AttributeError: 'numpy.ndarray' object has no attribute '__buffer__'). CPython's add_operators gives a type with bf_getbuffer a __buffer__ wrapper (and __release_buffer__ for bf_releasebuffer, see luc-eiti).
